EzWoW Font Changer bundled fonts
================================

Every font in this folder is a Modified Version (subset and merge) of fonts
licensed under the SIL Open Font License, Version 1.1, built by
scripts/build_fonts.py. None of them uses a Reserved Font Name.

EzWoW World Sans / EzWoW Sans Bold
  Latin, Hangul and Cyrillic letters from Pretendard
  Copyright (c) 2021, Kil Hyung-jin (https://github.com/orioncactus/pretendard),
  with Reserved Font Name 'Pretendard'.

EzWoW Round Gothic
  Based on Gothic A1. (C) Copyright HanYang I&C Co.,Ltd. All rights reserved.

EzWoW Soft Dodum
  Based on Gowun Dodum.
  Copyright 2021 The Gowun Dodum Project Authors (https://github.com/yangheeryu/Gowun-Dodum)

EzWoW Gothic / EzWoW Myeongjo
  Based on NanumGothic / NanumMyeongjo.
  Copyright (c) 2010, NHN Corporation (http://www.nhncorp.com),
  with Reserved Font Name Nanum, Naver Nanum, NanumGothic, Naver NanumGothic,
  NanumMyeongjo, Naver NanumMyeongjo, NanumBrush, Naver NanumBrush, NanumPen,
  Naver NanumPen.

EzWoW Neat Sans
  Based on SUIT. Copyright (c) 2022, SUNN (http://sun.fo/suit), with Reserved Font Name SUIT.

EzWoW Tech Sans
  Based on IBM Plex Sans KR. Copyright (c) 2017 IBM Corp. with Reserved Font Name "Plex".

EzWoW Jua
  Based on Jua. Copyright 2018 The Jua Project Authors.

EzWoW Do Hyeon
  Based on Do Hyeon. Copyright 2018 The Do Hyeon Project Authors.

EzWoW Black Han Sans
  Based on Black Han Sans.
  Copyright 2015 The Black Han Sans Project Authors (https://github.com/zesstype/Black-Han-Sans)

EzWoW Pen Script
  Based on Nanum Pen Script. Copyright (c) 2010, NHN Corporation (http://www.nhncorp.com),
  with Reserved Font Name Nanum (see the NanumGothic entry above for the full list).

EzWoW Gaegu
  Based on Gaegu. Copyright 2018 The Gaegu Project Authors.

EzWoW Song Myung
  Based on Song Myung. Copyright 2018 The SongMyung Project Authors.

EzWoW Pixel
  Based on Galmuri11. Copyright (c) 2019-2025 Lee Minseo (quiple@quiple.dev).

EzWoW Paperlogy
  Based on Paperlogy (SIL OFL 1.1, as stated in the font). Copyright © 2024 PT&

EzWoW Gugi
  Based on Gugi. Copyright (c) 2017 by TAE System & Typefaces Co.. All rights reserved.

EzWoW Diphylleia
  Based on Diphylleia. Copyright 2022 The Diphylleia Project Authors (https://github.com/JAMO-TYPEFACE/Diphylleia)

EzWoW Single Day
  Based on Single Day. Copyright 2015 DXKorea Inc. All rights reserved.

EzWoW Yeon Sung
  Based on Yeon Sung. Copyright 2018 The Yeon Sung Project Authors

EzWoW Poor Story
  Based on Poor Story. Copyright (c) YoonDesign Inc. All Rights Reserved.

EzWoW Stylish
  Based on Stylish. Copyright (c) 1992-2018 AsiaSoft Inc. Seoul Korea All Rights Reserved.

Letters the base fonts lack (accents, Greek, Cyrillic, kana, Han, symbols) come from
  Noto Sans, Noto Sans Symbols, Noto Sans Symbols 2:
    Copyright 2022 The Noto Project Authors (https://github.com/notofonts)
  Noto Sans KR, Noto Sans SC:
    Copyright 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.
